## Checked and working
Category required; field errors with focus on the first; email format; link availability check; US Real Estate needs brokerage, licence and 2-letter state; Back keeps the details; design arrows hide on the first and last design; colour pick; NFC pay button disabled until a full address (6-digit PIN, digits only); totals ₹2,598 (Custom + ₹99), $29 (US Digital, no address); bad coupon message; Place order; Open card, Download QR, Order another card; phone menu on every page; no horizontal scroll; every image has alt text and loads.

## Not tested here
Real payments (Razorpay, Stripe), the database and emails: the preview has no Worker. `/designs`, `/claim`, `/privacy`, `/create` return 404 in the preview only because it has no Worker routes; the suite checks them on `npm run dev`. Swipe gestures need a real touch device.
